# Search Profiles

Profiles define the ZIP/radius, make/model/year/mileage bounds, budget, maximum asking/reference ratio, maximum all-in ratio, KBB Good reference requirement, title requirement, repair exclusions, fraud ceiling, and minimum margin.

New profiles require a literal KBB Good reference by default. Comparable-market and MarketCheck values can be used for exploratory analysis only unless the profile explicitly disables the KBB requirement.

Start with a narrow profile. Widen radius or ratio only when the inbox is empty. A profile never turns seller claims into verified title history.
