# Friend Acceptance Test

Run this against the hosted URL with a fresh `USER` account and no developer assistance:

1. Sign up and sign out/in.
2. Create a search profile.
3. Import a Facebook listing with pasted text and phone screenshots.
4. Read the score breakdown and evidence confidence.
5. Follow the missing-information action.
6. Add a VIN, valuation, repair finding, and title note.
7. Run the inspection checklist.
8. Calculate and understand a suggested offer and maximum buy price.
9. Save/watch the listing and receive an alert without leaving the inbox open.
10. Confirm a second account cannot see the first account's listing.

Record date, URL, account roles, browser/device sizes, screenshots, and any point where explanation was required.
