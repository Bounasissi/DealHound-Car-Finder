# DealHound Quickstart

1. Open the hosted URL or run `pnpm dev` locally.
2. Create the first account; the first account becomes `OWNER`.
3. Create a search profile with ZIP, radius, budget, vehicle preferences, and repair exclusions.
4. On Facebook Marketplace, copy the listing text and URL, add any VIN and screenshots, enter the KBB private-party Good-condition value, then choose **Ingest & Evaluate**. The KBB value is saved before evaluation so the listing can immediately enter the ≤70% deal lane; without it, the default profile keeps the listing out of the qualified lane.
5. Review the score, evidence confidence, missing-information next action, title provenance, repairs, and offer calculator before contacting the seller.

DealHound provides estimates and evidence organization. It does not guarantee title status, repair cost, or profit.
